セッションをまたぐ場合は、このフォルダを最初に読むこと。

## 状況サマリ
- 現在のフェーズ: **詳細設計完了**（実装には未着手）
- ゴール: GitHub上にプロジェクト公開＋Webで遊べる状態にし、就活ポートフォリオとして使用

- 開発方針: ウォーターフロー。要件・設計が完全に固まってから実装に移る。
- バージョン管理: 未 `git init`。要件・設計の節目でユーザーが commit する想定。

## 担当分担
- **ユーザー単独で決定する事項**:
  - ゲームルール詳細（勝利条件・覆い被せ条件・盤外スタック仕様）
  - AlphaZero モデルアーキテクチャ（入力チャンネル・バックボーン・ヘッド）
  - コンポーネント分割の粒度（実装フェーズ）
- **相談して決める事項**: それ以外すべて
- **アバター・BGM・SFX**: 別エージェントが著作権フリー素材の候補を調査、ユーザーが採用判定
