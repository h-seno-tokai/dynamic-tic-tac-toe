## 担当分担

- **ユーザー単独で決定する事項**:
  - ゲームルール詳細（勝利条件・覆い被せ条件・盤外スタック仕様）
  - AlphaZero モデルアーキテクチャ（入力チャンネル・バックボーン・ヘッド）
  - コンポーネント分割の粒度（実装フェーズ）
- **相談して決める事項**: それ以外すべて
- **アバター・BGM・SFX**: 別エージェントが著作権フリー素材の候補を調査、ユーザーが採用判定

## 進め方

ウォーターフロー方式で実施。

```
要件定義 ─→ アーキテクチャ ─→ 技術選定 ─→ 詳細設計 ─→ 実装 ─→ デプロイ
   ✓           ✓              ✓            ✓         ✓        ✓
```
