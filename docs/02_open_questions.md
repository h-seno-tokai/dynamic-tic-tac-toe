### Q19. カスタムルール時の CPU 対応方針
- AlphaZero モデルは特定のルール（既定の 3x3 大中小2個）で学習する
- ユーザーがルールを変更した場合の選択肢:
  - A. ルール毎に別モデルを学習・配信（コスト大）
  - B. 既定ルール時のみ CPU 対戦可。カスタム時は「2人対戦専用」または簡易AI（ランダム/ヒューリスティック）
  - C. 入力をパディングしてある程度の汎化を狙う（精度劣化リスク）

推奨: B（既定 CPU + カスタム時は簡易AI）
