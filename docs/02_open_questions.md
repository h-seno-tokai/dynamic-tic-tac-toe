# 02. 主要設計決定事項

## 1. アルゴリズム・推論方式

**盤面サイズ別に 2 系統に分割**（詳細は `07_ai_design.md` §1）。

| 項目                 | 3x3                                              | 4x4                                             |
| -------------------- | ------------------------------------------------ | ----------------------------------------------- |
| アルゴリズム         | alpha-beta + 反復深化 + Zobrist TT + PV 順序付   | AlphaZero 系（4x4 専用ネット + MCTS、自己対戦） |
| クライアント推論方式 | TypeScript 直接実行（ONNX 不使用）               | ONNX Runtime Web                                |
| ディスパッチ場所     | `src/ai/worker/aiWorker.ts`（`boardSize === 3`） | 同（`boardSize === 4`、ONNX は **遅延ロード**） |
| 学習                 | 不要（オンライン探索のみ）                       | PyTorch + RTX 2080（自己対戦）                  |

共通:

- AI スレッド: TypeScript Web Worker（UI スレッドと分離）
- ONNX のロード失敗は 3x3 を阻害しない（`init` は即 `ready` を返す）

## 2. ゲームルール仕様

| 項目             | 決定内容                                               |
| ---------------- | ------------------------------------------------------ |
| 勝利条件         | 縦・横・斜めいずれかに N 個揃う（N = 盤面サイズ）      |
| 引き分け条件     | 合法手が無い                                           |
| 覆い被せ         | より小さい駒の上のみ可。自分の駒の上にも可             |
| 盤外スタック     | サイズ別カウントのみ（物理スタック取り出し順制約なし） |
| ルールプリセット | 2種固定（3×3 クラシック / 4×4 巨大入り）               |
| 完全カスタム UI  | 提供しない（コード上は GameRules 駆動で将来拡張可）    |

詳細は [06_data_model.md](06_data_model.md) 参照。

## 3. AI ネットワーク設計（4x4 専用）

3x3 はネットワーク非使用（alpha-beta 解析）。AlphaZero ネットは **4x4 専用に縮小** した。

| 項目           | 決定内容                                                       |
| -------------- | -------------------------------------------------------------- |
| 入力テンソル   | (1, 27, 4, 4)（旧ユニバーサル形状を流用、ch 25/26 は退化）     |
| バックボーン   | ResNet **6 ブロック × 96 ch** + BN + ReLU                      |
| Policy ヘッド  | conv ベース（Place 64 + Move 256 = 320 logits）                |
| Value ヘッド   | GAP + MLP + Linear (64→3) **WDL ロジット**（旧 tanh から変更） |
| パラメータ数   | 約 1.03M / ONNX 約 **3.92 MB**（float32）                      |
| 学習パッケージ | `ai-training/src/dttt_train_4x4/`（旧 `dttt_train/` と並列）   |

詳細・学習ハイパーパラメータ・run 履歴は [07_ai_design.md](07_ai_design.md) 参照。
