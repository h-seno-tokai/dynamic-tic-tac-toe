# 02. 主要設計決定事項

## 1. アルゴリズム・推論方式

| 項目                 | 決定内容                                   |
| -------------------- | ------------------------------------------ |
| クライアント推論方式 | ONNX Runtime Web                           |
| 強化学習アルゴリズム | AlphaZero 系（自己対戦のみ、完全教師無し） |
| MCTS 実装場所        | TypeScript Web Worker（UI スレッドと分離） |

## 2. ゲームルール仕様

| 項目             | 決定内容                                               |
| ---------------- | ------------------------------------------------------ |
| 勝利条件         | 縦・横・斜めいずれかに N 個揃う（N = 盤面サイズ）      |
| 引き分け条件     | 合法手が無い                                           |
| 覆い被せ         | より小さい駒の上のみ可。自分の駒の上にも可             |
| 盤外スタック     | サイズ別カウントのみ（物理スタック取り出し順制約なし） |
| ルールプリセット | 2種固定（3×3 クラシック / 4×4 巨大入り）               |
| 完全カスタム UI  | 提供しない（コード上は GameRules 駆動で将来拡張可）    |

詳細は [06_data_model.md](06_data_model.md) 参照。

## 3. AI ネットワーク設計

| 項目               | 決定内容                                          |
| ------------------ | ------------------------------------------------- |
| 入力テンソル       | 4×4×27 ch（最上段 + 任意位置 + 残数 + mask）      |
| バックボーン       | ResNet 8 ブロック × 128 ch + BN + ReLU            |
| Policy ヘッド      | conv ベース（Place 64 + Move 256 = 320 logits）   |
| Value ヘッド       | GAP + MLP + tanh                                  |
| パラメータ数       | 約 2.4M / ONNX 約 9.6 MB（float32）               |
| カスタムルール対応 | ユニバーサル CNN で両プリセットを単一モデルで扱う |

詳細は [07_ai_design.md](07_ai_design.md) 参照。

## 4. インフラ・その他

| 項目             | 決定内容                                                   |
| ---------------- | ---------------------------------------------------------- |
| ホスティング     | GitHub Pages                                               |
| 戦績保存         | localStorage（勝敗カウントのみ、手順履歴の永続化なし）     |
| テーマ           | ダーク / ライト（OS 設定尊重、localStorage 永続化）        |
| 多言語           | 日本語 / 英語（i18n 対応済み）                             |
| チュートリアル   | v1 未実装。ルール説明画面で代替                            |
| アクセシビリティ | WCAG 2.1 AA レベル目標                                     |
| 初回ロード目標   | ゲーム本体 10 MB 以内。モデル重みは CPU 選択時に遅延ロード |
| CPU 難易度段階数 | 10 段階                                                    |
| リプレイ永続化   | 不要（戦績のみ保存）                                       |
