## 3. ユーザーアバター

### ユーザー要件（参考）

- カラー（モノトーン不可）
- 男性 / 女性 のバリエーション
- 長髪 / 短髪 のバリエーション
- 親しみやすい絵柄

### 採用: DiceBear - Avataaars

- ソース: https://www.dicebear.com/styles/avataaars/
- プレビュー: https://www.dicebear.com/playground/?style=avataaars
- ライセンス: MIT + Free for personal and commercial use（Pablo Stanley 作、帰属任意・推奨）
- 形式: SVG / PNG（HTTP API で動的生成可）
- 採用理由:
  - DiceBear 系で最もカスタマイズ要素が多い（髪型・髪色・肌色・服装・アクセサリ・口・目）
  - 長髪 / 短髪 / 髭 / 眼鏡 / 帽子など要件を満たす豊富な選択肢
  - フラットなカートゥーン調で親しみやすい・カラーフル

### 実装仕様

- プリセット 16 種のシード固定アバターを用意
- ローカル2人対戦のセットアップ画面でプレイヤー1 / 2 がそれぞれ選択
- DiceBear API をオンライン呼び出し（オフライン動作のためキャッシュ済み SVG を利用）

### 不採用（参考）

- Lorelei / Adventurer: Avataaars が選ばれたため不採用
- Notionists / Notionists Neutral: モノトーンのため不適
- Bottts: ロボット型で CPU と紛らわしい
- Shapes: 抽象で人物表現要件と合わず

## 4. CPU アバター

### 採用方針: ユーザーアバターと同じ DiceBear Avataaars を使用

Bot icon + 難易度バッジ案から転換し、ユーザーアバターと同ライブラリで統一。

### 実装仕様

- スタイル: DiceBear Avataaars
- シード: `"cpu-robot"`（全難易度共通の固定シード）
- 描画: `UserAvatar` コンポーネント（`seed="cpu-robot"` を渡す）
- 名前表示: 「AI」固定（難易度番号は対戦設定画面の Slider で確認）

### 採用理由

- ユーザーアバターと同じコンポーネント・ライセンスで実装が最小化
- DiceBear の seed 機能でアセット不要・オフライン動作
- 「AI らしい見た目」が seed で自然に得られる
