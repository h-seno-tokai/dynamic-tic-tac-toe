## 4. CPU アバター（確定: プログラム的生成）

### 採用方針: アセット不要、コードで生成

ユーザー指摘「難易度がしっかりわかる素材が無い」を踏まえ、**素材を探さずに自前で表現する**ことに方針転換。

### デザイン仕様

```
┌─────────────────┐
│   [Bot Icon]    │   ← Lucide-react `Bot` アイコン
│      LV.7       │   ← 難易度番号（1〜10）
└─────────────────┘
   color tier: gold
```

### 難易度ティア → 視覚表現

| 難易度 | 呼称 | 色（ライト/ダーク） | 装飾 |
|---|---|---|---|
| 1〜3 | Bronze (見習い) | `#CD7F32` 系 | なし |
| 4〜6 | Silver (中級) | `#C0C0C0` 系 | 微弱な outline |
| 7〜9 | Gold (達人) | `#FFD700` 系 | 静止 glow |
| 10 | Master (最強) | プラチナ + 黒 | アニメーション pulse |

### メリット
- アセット調達ゼロ・ライセンス問題ゼロ
- 10段階すべてに対応
- テーマ（ダーク/ライト）対応が容易
- アクセシビリティ対応容易（`aria-label="難易度7のCPU"` 等）
- ポートフォリオ的にも「自前でデザインした」というプラス評価

### 実装担当
- 詳細デザイン（具体カラーコード・サイズ・SVG マークアップ）は実装フェーズで決定
